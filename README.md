# env-config

Repositório contendo conjunto de scripts para customização e configuração de ambientes de trabalho.

- [gitClone](gitClone/README.md) - Script de clone de repositórios com configuração automática de identificação
  previamente cadastrada.
- [gitMassClone](gitMassClone/README.md) - Script de clone de repositórios em massa e organização de diretórios.
- [vpnctl](vpn/README.md) - Script para gerenciar conexões VPN NetExtender e Tailscale.
    - [split-dns](vpn/split-dns/README.md) - Script para configurar consulta DNS em split-DNS (válido apenas em VPNs com
      split-tunnel).
